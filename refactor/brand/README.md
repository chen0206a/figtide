# FigTide 品牌资产

图标方案：设计画布「品牌 · FigTide 图标」中的方向 B · 波浪 F。纵坐标轴是 F 的竖笔，两道波浪是横笔，上方一道以朱红数据点收尾，下方一道浅蓝浪线。

| 文件 | 用途 |
|---|---|
| `figtide-icon.svg` | 主图标（墨色底），显示尺寸 > 24 px 时使用 |
| `figtide-icon-small.svg` / `favicon.svg` | 小尺寸版（≤ 24 px），中间横笔拉直、去掉浪线 |
| `figtide-icon-reverse.svg` | 深色背景上使用（白底墨线） |
| `figtide-icon-mono.svg` | 单色线稿，打印或单色场景 |
| `figtide-avatar.svg` | 圆形头像（GitHub 组织、社交账号） |
| `favicon.ico` | 16 / 32 / 48 px |
| `figtide-app.ico` | 16–256 px，留给以后的 Windows 桌面版 |
| `png/figtide-icon-*.png` | 64–1024 px，用于 apple-touch-icon、PWA 和桌面版 |
| `png/favicon-*.png` | 16 / 32 / 48 px |
| `png/social-preview.png` | 1280×640，GitHub 社交预览和 og:image |
| `social-preview.html` | 社交预览图的源文件，改文字后可重新截图 |

## 字标

- 英文：**Fig** 字重 800 + **Tide** 字重 400，Inter，字距 -0.03em 到 -0.04em。
- 中文名：图汐，思源黑体（Noto Sans SC）字重 700，和英文之间用一条竖线隔开。

## 颜色（沿用现有 token）

| 用途 | 颜色 |
|---|---|
| 墨色（图标底、文字） | `#0E1116` |
| 朱红（数据点、强调） | `#D55E00` |
| 浪线（深色底） | `#2F9BD6` |
| 浪线（浅色底） | `#0072B2` |
