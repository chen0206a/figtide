## 09-1 收敛蓝色

**问题**：任务 02 把旧的强调色映射成了 `--lf-link`，导致大量辅助信息显示成蓝色（实验卡片里的时间、参数/指标标签和数值、「已选 0 个实验」「1 / 1 条记录」，数据页的「v1 · 3 行」、表格底部数字，编辑器左栏的「3 行 · 3 字段」「查看字段 3」）。

**规则**：`--lf-link` / `--lf-info` 只能用于：
- 真正的链接（`<a href>`、文字按钮，例如「新建项目」「全部实验」「列设置」）；
- 选中和当前状态（导航、标签页、选中行的底色或边框）；
- 焦点环；
- 状态标签中「进行中」的那一种。

其他文字统一改为：说明文字用 `--lf-text-3`；数字、版本、ID、行数等元信息再加上 `.lf-mono`。

**做法**：
1. 运行 `grep -rn "var(--lf-link)\|var(--lf-info)\|var(--lf-focus)" frontend/src --include=*.css`，逐条判断属于上面哪一类，不属于的改掉。
2. TSX 里的内联样式和 className 也要查一遍：`grep -rn "lf-link\|--lf-info" frontend/src --include=*.tsx`。
3. 把改动的选择器列表写进 TEST-RESULTS。

**验收**：在 1440px 下截取实验页、数据页、编辑器三张图。除链接、选中状态和「进行中」标签以外，看不到其他蓝色文字。

## 09-2 统一表格样式

**问题**：首页「最近实验」的表头有灰底、`ACCURACY` 被转成全大写，而旁边「研究项目」的表头没有灰底；数据页表格只占约六成宽度，表头底色在中间断开。根因是全局 `th` 样式（`text-transform`、背景）渗进了组件。

**做法**：
1. 新建 `frontend/src/styles/table.css`，定义 `.lf-table`：
   - 表头：背景 `--lf-surface-2`，文字 `--lf-text-3`、字重 500，**不转大写**，上下边框 `--lf-divider`；
   - 单元格：上下内边距 11px，左右 12px；第一列和最后一列额外加 12px，与卡片边缘对齐；
   - 数字列加 `.num` 类：右对齐，使用 `.lf-mono`；
   - 行悬停时使用 `--lf-surface-2` 底色。
2. 删除全局的 `th { text-transform … }` 和全局表头背景，然后检查所有 `<table>` 是否都加上了 `lf-table`：首页两张表、数据表 `DataTable`、实验对比 `Comparison`、评估 / 分类结果表、版本历史。
3. 数据表铺满宽度：`width: 100%`。行号列固定 56px，用 `--lf-text-3` 和等宽字体。字段类型为 `number` 的列右对齐。
4. 数据表里的空值显示为「空」：`--lf-warning` 文字配 `--lf-warning-soft` 底色，加 `aria-label="空值"`。不要显示成 0，也不要留成完全空白。底栏说明文字写「空值保留为空，不当作 0」。

**验收**：`DataTable.test.tsx` 增加 2 个断言：空值单元格的文字是「空」；数字列有 `num` 类。首页两张表的表头样式一致。

## 09-3 实验页表格视图（新增功能）

参考 `png/Experiments.png` 和 `source/Experiments.dc.html`。

1. **视图切换**：筛选栏右侧加「表格 / 卡片」分段按钮，默认是表格。选择记在 `localStorage` 的 `labflow-experiments-view` 里。读写要包在 try/catch 中，存储不可用时退回默认值。原有卡片视图保留，不改。
2. **新组件 `experiments/ExperimentsTable.tsx`**：
   - 列依次为：勾选框 | 实验（编号 + 名称，第二行显示标签；基线实验后面加「基线」标记） | 状态 | 参数列 | 指标列 | 数据版本（链接到数据页） | 更新时间 | 操作。
   - 参数列和指标列上方各有一个分组表头「参数」「指标」。
   - **列的来源**：从当前项目所有实验的 `parameters` 和 `metrics` 中统计键名。默认显示出现次数最多的前 4 个参数、前 3 个指标。「列设置」弹层里可以勾选显示哪些列，按项目记在 `labflow-experiment-columns:{projectId}`。
   - **排序**：点击列名排序，再点一次反转方向，表头设置 `aria-sort`。默认按第一个方向明确的指标降序排序，没有这样的指标时按更新时间倒序。空值永远排在最后。
   - **最优值高亮**：复用 `components/home/homeData.ts` 中的 `metricDirection` / `bestIndex`，先把这两个函数移到 `lib/metrics.ts`，首页改为从新位置导入。只有方向明确的指标才高亮，用 `--lf-accent`、字重 600。
   - 数字右对齐，使用等宽字体；缺失值显示「—」，颜色用 `--lf-text-3`。
   - 状态用 `.lf-chip`：planned 用 neutral，running 用 info，completed 用 success，failed 用 danger。
   - 操作列是一个「⋯」菜单，包含「编辑」「复制配置」，复用卡片视图里已有的回调。
3. **选择栏**：只在选中至少 1 个实验时出现，浮在列表底部，样式是深色胶囊（`position: sticky; bottom: 20px`），内容为「已选 N 个实验（最多 8 个）· 基线 … · 清空 · 对比所选实验」。全部取消后选择栏消失。同时删除任务 03 为避免遮挡而加的列表底部留白，这块留白在记录少的时候会造成大片空白。**勾选、基线和对比的逻辑全部复用现有代码**，只改呈现方式。
4. **日期格式**：新增 `lib/format.ts`，导出 `formatDateTime(iso)`，格式为「2026-10-23 17:10」（本地时区）；再导出 `formatDate`，当年的日期显示「10/23」，跨年显示「2025-10-23」。实验卡片、表格和版本历史统一改用这两个函数，不再出现「10/23/2026, 5:10:18 PM」这种格式。

**验收**：
- 单测：列推断、排序（空值在最后）、视图和列设置的持久化（包括存储不可用的情况）、选择栏的显隐，至少 6 项。
- E2E：更新 `e2e/experiments.spec.ts`，在表格视图下完成勾选两个实验并进入对比；切换到卡片视图后，原有断言仍然成立。

## 09-5 编辑器：论文尺寸预设与单序列图例

参考 `png/Editor.png`、`png/Editor-double.png`。

1. **画布工具栏**：加一个分段按钮「单栏 · 88 mm / 1.5 栏 · 120 mm / 双栏 · 180 mm」。点击后设置 `publication.enabled = true`、`publication.widthMm = 88 | 120 | 180`。这是现有的 schema 字段，**不新增配置字段**。`style.width` 和 `style.height` 不变。右侧显示等宽灰字 `宽 × 高 mm · 字号 pt · DPI`，其中高度按 `widthMm × style.height / style.width` 计算。
2. **纸面上方加一条 mm 标尺**（每 10 mm 一个刻度），只在 `publication.enabled` 时显示，使用 `aria-hidden`。刻度间距按当前缩放和实际显示宽度计算。
3. **属性面板「外观」页**：加一个「论文尺寸」分组，包括开关、三个预设和「自定义」。下面是四个输入：成品宽度（50–300 mm，与后端校验范围一致）、高度（按比例换算，只读）、字号（4–24 pt）、PNG 分辨率（72–1200 DPI）。附一句说明：「预设宽度是常见期刊版心的近似值，投稿前以期刊要求为准」。先确认现有的 `publication` 输入控件在哪个标签页里（可能在「专业」页），**不要重复做一套**：要么把它挪到「外观」页，要么在「外观」页里复用同一个组件。
4. 先读 `editor/publication.ts` 里的 `renderConfig` / `publicationMetrics`，确认物理尺寸开启后预览是如何换算字号的。三个预设切换时，画布上的文字和图形的相对比例应该发生变化（单栏时文字显得大，双栏时显得小）。如果当前实现并不按物理尺寸预览，在汇报里说明，**不要自己发明新的换算方式**。
5. **单序列图例**：`model.ts` 的 `defaults()` 在只有一个序列且没有分组时，设置 `legend.show = false`。只影响新建的图，已保存的图不变。补一个单测。
6. 编辑器左栏的「3 行 · 3 字段」「查看字段 3」这类元信息按 09-1 改成灰色。

**验收**：
- 单测：预设写入 `publication`、高度换算、单序列默认隐藏图例。
- E2E：新建图 → 选择「双栏」→ 保存 → 刷新 → 预设仍是双栏 → 导出 PDF，页面宽度为 180 mm。用现有的 `scripts/check-pdf.py` 或已有的 PDF 断言方式检查。
