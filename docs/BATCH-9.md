# 第九批：前端流畅度与界面细节

保留现有 LF 标识和浅石墨色首页，优先处理实际输入、加载与画布布局。本批没有修改后端、数据库、API 字段或图表配置 schema。

## 修改内容

- 同版本 Plotly 3.7.0 改用官方 Cartesian 分包，继续按需加载编辑器。包含现有图表所用的 scatter、bar、box、violin 等模块；热力图、统计与评估仍使用原有计算逻辑，不降采样、不改实验数据。
- 标题、字体、坐标、图例等仅布局变化时使用增量 `relayout`；数据/序列变化仍走 `react`。删除的范围、刻度与定位属性明确传 null，防止重置后留下旧值。每次绘制保留独立布局快照，避免 Plotly 修改输入影响下次比较。
- 输入状态立即更新，绘图采用 React 延后渲染与帧调度；过期任务跳过，绘图任务串行。画布更新中有状态提示，导出按钮等待对应最后一次配置的画布完成；结果面板使用对应配置并在更新中暂停操作。
- 本机草稿合并 250 ms 内的连续写入；刷新、离开和卸载前同步冲刷。正式保存取消待写草稿，避免旧草稿重新出现。此行为不等同于自动保存到 MySQL，正式保存入口不变。
- 首页项目和最近图表先各显示 8 项，按需增加；当前项目优先，项目支持名称/简介搜索。减少隐藏列表 DOM，不删除任何历史。
- 数据表延后搜索过滤，复用稳定的行组件；分页、排序、缺失值和字段显隐保持原功能。侧栏宽度持久化合并为 150 ms，拖动即时反馈。
- 画布随窗口、侧栏和底部面板自动适配，手动缩放后保留用户比例；“适合窗口”重新启用自动适配。缩放只影响显示，不改变配置尺寸及导出。
- 统一焦点、控件、属性标签、滚动区和状态栏；提高辅助文字对比度，减弱画布阴影与点阵。弹窗采用短时透明度/位移动效，取消全屏背景模糊。首页保留图标→站名→功能区的顺序，入场由约 1.8 s 缩至约 0.93 s；再次返回无等待，减少动态效果设置生效。
- 编辑器首次加载使用结构骨架与真实加载提示；顶部增加可操作的“复用”入口，调用已有模板/映射功能。

## 验证方法与边界

最终生产构建的三轮中位数（2026-10-20，Chrome 155.0.8059.84）：

| 测量 | 优化前 | 优化后 |
|---|---:|---:|
| 编辑器 JS 原始大小 | 4,957,544 B | 1,544,904 B |
| 编辑器 JS gzip | 1,507,777 B | 514,851 B |
| 首次打开已有图表 | 2625 ms | 1102 ms |
| 27 字符输入用时 | 10454 ms | 593 ms |
| 每轮 input→下一帧 P95 的中位数 | 470 ms | 29 ms |
| 连续输入的草稿写入 | 27 次 | 1 次 |
| 表格搜索输入至过滤完成 | 301 ms | 255 ms |
| 首页 DOM 节点（实际列表） | 2258 | 530 |

输入 P95 三轮分别为优化前 434/485/470 ms，优化后 5/29/37 ms。逐轮绘图次数有变化，主要收益是布局变化不再重新计算整组 trace，而非限制每秒绘图次数。可核对 [完整原始记录](test-evidence/frontend-experience.json)；此表不是所有数据与设备的性能承诺。

Vitest 74/74，生产构建通过；Chrome 25 个用例验证通过。最终完整运行 23 通过、2 项资源相关失败，停止并行构建后定向重跑 2/2 通过；详细错误与复查记录保留在 [测试记录](TEST-RESULTS.md)，不掩盖失败或改为 skip。

性能对比使用生产构建、同机 Chrome、绘图页禁用缓存并设置 2 倍 CPU 限速、1440 × 900 窗口，各运行三次。数据是明确标记的合成曲线（1200 点）与 10000 行、8 列表格。标题连续输入 27 个字符，记录 input 事件到下一次 requestAnimationFrame 的 P95；这不是标准 INP 或帧率保证。冷启动时间包含点击已有图表至数据绘制就绪。表格搜索在独立页面进行，未设置 CPU 限速，计时包含输入和过滤；对比两版保持相同条件。首页节点数是对应实际项目列表的观察值，回归期间会新增合成测试项目，不作为项目数量完全受控的渲染耗时基准。

完整回归通过真实 Java API/MySQL 创建独立合成测试项目，检查 11 类图、数据导入与处理、实验对比、模板、历史、备份恢复以及 SVG/PNG/PDF。新增刷新冲刷草稿、最终 SVG/保存配置一致、轴重置与 1280–1920 窗口适配；另外检查 2400 × 2400 大画布、手动缩放保留、键盘访问及减少动态效果。

较大数据的重新计算/序列变更仍在主线程绘图；没有宣称所有数据规模均达到 60 fps。编辑器包仍超过 Vite 默认 500 kB 提示线，未隐藏该警告。PDF 字体边界沿用第八批。本轮未修改 Java，Java 56 项是上一批通过记录，不计为本轮重新执行。
