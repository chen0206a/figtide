# Okabe–Ito：实际角色轮廓色检查

默认模板为分区机制、风格nature-flat、配色okabe-ito。实际使用四个角色：参与者actor、过程process、模型model、注释note；不加入未使用的data/output，不比较浅填充，不比较P/编号等符号的底色。轮廓按原型映射；所有原始色值和ΔE≥20阈值保持不变。

数值由原后端dev.labflow.review.ColorVision计算（scripts/capture-diagram-color-audit.cjs调用当前已编译的Java类，无公式副本）。protan/deutan/tritan为三种完全色觉缺陷模拟，采用CIEDE2000。
