# GLOSSARY — 界面用词

界面上同一个东西只用一个词。界面文字、`aria-label`、`document.title`、toast、空状态、E2E 选择器都以此表为准。

| 统一用词 | 指什么 | 不再使用 |
| --- | --- | --- |
| **研究项目**（简称「项目」） | 顶层容器 | 工作区项目 |
| **本地工作区** | 只用在顶栏的范围标识 | — |
| **数据集** | 一份上传文件及其所有版本 | — |
| **版本 v1 / v2** | 数据集或图表的某个版本，统一写成「v1」 | 「版本 1」「数据版本 1」混用 |
| **新数据集** / **新版本** | 上传新文件 / 给已有数据集追加版本 | — |
| **图表** | 保存的单位 | 图版、FIGURE、图（作为对象名时） |
| **科研绘图** | 只作为导航模块名 | — |
| **序列** | 图里的一条数据线、一组柱 | 图层 |
| **模型设置** | 配置模型的入口（顶栏按钮、首页卡片、助手里的链接） | 模型连接（作为入口名时）、配置模型连接 |

## 说明

- **新数据集 / 新版本** 与接口语义一致：`POST /datasets` 是新数据集，`POST /datasets/{id}/versions` 是新版本。审计里「统一叫新数据版本」的建议不采纳。
- **版本** 一律写成 `v1`、`v2`，包括图表版本和数据版本；数字前不加「版本」「数据版本」。
- **图表** 是保存的单位。对象名不单独写「图」；「科研绘图」只作为导航模块名，「绘图助手」是功能名。
- **模型设置** 是入口名。模型服务不可用时可以说「未连接」「连接模型服务」，但入口按钮、对话框标题、助手里的链接统一叫「模型设置」。
