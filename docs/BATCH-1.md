# 第一批功能增量

范围：导入确认、草稿恢复、数据表增强、基础管理与界面细节。所有修改位于 LabFlow 独立仓库。

## 实现

- 上传先预览，再确认类型、X/Y/分组/误差角色与缺失符号。支持 CSV 分隔符和 XLSX 工作表选择；取消预览不新增数据版本。错误数值定位到逻辑行和字段，原文件保持不可变。
- 统一 ImportRules schema 1，预览与提交共享 Java 解析器；字段元数据同步到 TypeScript 与绘图 defaults。V2 迁移增加解析规则与项目归档字段，原图表 schema 1 保持兼容。
- 草稿按项目与图表保存到浏览器本机存储。刷新后重新进入对应图表可恢复，正式保存仍产生 MySQL 版本。存储失败有提示；版本冲突可另存副本。
- 数据表增加搜索、排序、列宽拖动、字段隐藏、缺失行筛选与缺失单元格提示。表格查看不改动图表过滤或原数据。
- 管理项目支持搜索、重命名、简介编辑、归档和恢复。绘图器支持另存副本。
- 统一主界面与弹窗色调；导航与恢复默认使用统一确认框。编辑器侧栏可折叠、拖动宽度、键盘调整，并记住设置。
- 修复首行缺失导致该列无法全局搜索，以及保存后重新打开可能读取旧查询缓存的问题。

## 运行

```powershell
cd 'D:\RAG-agent项目\LabFlow'
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

后端启动自动执行 Flyway V2。访问 http://127.0.0.1:5176 。保留既有 MySQL 数据；归档不删除文件和图表。

## 本轮边界

- CSV 仍要求 UTF-8，文件和数据规模上限不变。不含坏行内联修改、编码自动转换、小数点/千分位规则、日期类型或多表合并。
- X/Y 角色是初始化提示，修改已有图表的数据集仍保留既有样式，不擅自套用新角色。
- 草稿保存在当前浏览器与来源下，清理浏览器数据会删除草稿；没有跨设备同步。一个项目的新图草稿槽位为一个，已有图表按图表 ID 分开。
- 数据预览是前端分页与筛选，当前读取完整版本数据；没有扩展原有规模上限。
- 未实现实验关联/对比、多子图、PDF 或高级统计；这些属于后续批次。
