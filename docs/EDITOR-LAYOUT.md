# 绘图编辑器信息层级整理（2026-10-20）

## 检查结论

原编辑器将字段表、11 种类型、图层、视觉预设全部纵向展开，右侧单个“图表”页面又混合字段映射、字体、画布、图例和过滤。左右面板有重复的属性入口。随着科研功能增加，用户需要在长面板中寻找基础操作。

## 参考与取舍

- [RAWGraphs 的界面演进](https://www.rawgraphs.io/post/a-short-history-of-rawgraphs-interface)：官方文章明确区分 data / mapping / layout，并通过分步方式支持返回修改。FigTide 借鉴职责分离，保留实时画布，避免将已有编辑流程改成必须顺序完成的向导。
- [Lyra](https://github.com/vega/lyra)：图形对象与数据字段绑定、直接操作图形。FigTide 保留点击曲线选中序列和对应属性面板，左侧图层只保留图表和序列。
- [Vega Editor](https://github.com/vega/editor)：定位为 Vega / Vega-Lite IDE。它可作为配置可复现性的参考，但代码编辑器并不适合 FigTide 的无需编程定位，因此不引入 JSON 主编辑区。

仅参考交互组织原则；没有复制这些项目的代码或素材，也不宣称遵循某个项目的官方设计认证。

## 本轮实现

- 数据集及版本摘要常驻；完整字段列表按需展开，并限制长字段列表的滚动高度。
- 新图表默认展开类型选择；打开已保存图表只显示当前类型，点击可展开全部 11 种。类型选项改为两列紧凑图标列表。
- 左侧删除重复的坐标轴、注释、专业属性入口；这些功能保留在右侧导航。
- 右侧增加“外观”分区，集中标题、字体、画布、图例；“图表”分区保留字段映射与过滤。
- 画布、图例、过滤、图层操作默认折叠；其他属性组可用鼠标或键盘折叠。
- 视觉预设按需展开；顶部“复用”仍可直接访问模板和跨数据集复用。
- 属性导航使用两行三列，选中状态暴露给辅助技术；修复旧固定高度导致的第二行遮挡。
- 画布周边使用中性灰背景，统一蓝色选中态。图表输出字体、数据、配置 schema 和后端 API 没有改动。

## 验收范围

通过真实 MySQL / Java 后端运行浏览器测试；测试按新的“外观”入口导航，并在需要时展开图表类型或画布设置。增加分区互斥、键盘展开字段、仅切换面板不产生脏配置、1280 / 1440 / 1920 宽度画布适配及截图验收。
