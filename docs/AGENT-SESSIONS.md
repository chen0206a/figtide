# 会话累计预算与断线恢复

2026-10-22。工具协议仍为1、提示词仍为v6；本次改变运行控制与恢复机制，没有更改模型工具或提示词。

## 使用

助手中展开「会话预算」可在新对话开始前选择60,000 / 180,000（默认）/ 360,000 / 600,000额度。额度跨提案续改、追问、拒绝后的继续交流累计，每轮最多60,000。已有提案可以在预算不足时确认应用或拒绝；开始新对话是明确的新预算，不会自动重置或加额。

额度使用现有Harness的保守工作量单位：每次请求按UTF-8字节及固定开销估算，响应计入已收到的用量或字节估算中的较大值。它不是精确tokenizer，不是人民币价格，也不承诺第三方服务实际账单的硬上限。界面单独显示模型上报tokens。

开始一轮前，在MySQL事务中锁定会话并预留本轮最坏额度。剩余额度不足整轮时，下调本轮上限；不足2,000时在调用模型之前429返回。结束且用量完整时按保守实际值结算，返还未用预留。调用发出后取消、超时、服务中断等导致用量不明时，保留至少整轮预留，不误当成免费失败。收到异常超限用量时如实记录，剩余额度归零，不继续调用。

刷新或重新打开当前标签页的相同图表，读取已有运行并继续轮询，不重新提交模型。网络故障采用最长8秒的读取退避；「重新连接」只执行GET。即使首次POST已执行但响应丢失，也能凭发送前生成的请求ID找回原任务。

## 数据与恢复范围

Flyway V7新增 `agent_sessions`，保存项目、图表、不可变数据版本归属、总额、已用、预留、上报tokens和用量不明次数。run增加 `session_id / request_hash / reservation / session_charge`。V8增加会话轮次序号，保证同毫秒提交的记录也按实际顺序恢复。

会话预算与审计持久存MySQL；会话归属不能跨项目、图表或数据版本复用。每段会话同一时刻只允许一个活跃运行。修改模型不会绕过预算；预算是工作量额度，不依赖模型价格。

浏览器sessionStorage按项目、图表、数据版本隔离，只保存一个运行UUID，不保存密钥、提示词、图表配置、完整对话、原始数据或授权勾选。浏览器禁止存储时显示恢复不可用提示，仍可使用当前页面。未发送的输入不保存。

服务端近期对话、原始配置基线与可应用提案只在运行内存缓存中保留，读取最多最近12轮。恢复时基线来自服务端；前端比较配置内容、保存版本与归属。与当前本机草稿不同则禁用直接应用，继续修改通过现有安全合并流程处理。保存版本已变化时不恢复可应用候选。

后端重启/缓存淘汰后，预算、审计仍在，未完成运行记为中断并保守结算；历史不含完整配置，不能复活旧提案，需要按当前画布重新生成。恢复不等于持久化完整聊天，也不会恢复自动运行。关闭标签页可能清除sessionStorage，仍可从审计查看记录。普通模块切换取消该编辑器拥有的在途运行，保留可恢复标识与预算；收起助手不取消。

## API

`POST /api/projects/{p}/agent/runs` 新增可选字段：

- `request_id`：客户端预先生成的UUID。相同项目、同ID及完全相同请求内容返回原运行；不同内容409，不重新调用模型。适用于当前单后端实例模式。
- `session_id`：复用已有会话。续改父提案自动继承其会话，不能换预算。
- `session_budget`：仅新对话允许，默认180000、范围60000–600000；不能与session_id或parent_run_id同时提交。
- `user_message`：本轮原始消息（最多2000字），仅用于内存恢复对话；实际发给模型的有界history仍在prompt中。两者都不落审计数据库。

响应新增 `session_id` 和 `session`：`max_budget / used_budget / reserved_budget / remaining_budget / reported_tokens / uncertain_runs`。现有无会话的客户端仍可用：首轮自动建立默认会话，续改自动继承。

`GET /api/projects/{p}/agent/runs/{id}/resume` 返回已有运行、会话用量、存活的最近对话和可用候选（含可信基线）。历史缓存不存在时只返回持久摘要和说明，不恢复原始配置。不创建新run、不调用模型、不修改画布或科研数据。沿用状态读取中的终态审计补写重试：数据库此前不可用时，恢复读取可能补写审计和预算结算，事务确保不重复结算。未知或跨项目标识404。

请求预留、审计初始行在同一事务中写入；终态、父提案替代、预算结算也在同一事务中完成。审计失败不能释放额度或允许应用；重试成功只结算一次。进程恢复依据已持久的预留，不能因丢失内存而返还未知用量。
