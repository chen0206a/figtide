# 第二批：实验关联与对比

## 设计与接口约定

实验的 parameters / metrics 继续使用 JSON 对象，兼容现有记录。新增 status（planned/running/completed/failed）、tags（字符串数组）、revision（乐观锁）与 dataset_version_ids（同项目版本 ID 数组）。实验与数据版本采用独立关联表，一个实验可关联多个版本，一个版本也可被多个实验引用。引用固定版本，不随最新版本漂移。

现有 GET/POST/PUT /projects/{p}/experiments 接口保留。新版 PUT 携带 revision，冲突返回 409；旧客户端省略新增字段时保留原有值，创建时使用默认值。参数表单支持数值、文本、布尔和 JSON，指标表单支持数值及缺失；高级 JSON 保留旧记录中的嵌套结构和非数值信息。只有有限数值参与指标差值与绘图。

POST /projects/{p}/comparisons 接收 experiments:[{id,revision}]、baseline_id、metric、direction(higher/lower)、chart_type(bar/scatter)。服务器锁定并验证选中的实验修订，再生成不可变数据版本，返回 Dataset。该版本的 source_meta 包含完整实验快照、关联的数据版本、基线、指标、优劣方向与快照时间。图表继续引用 datasetVersionId，chart schema 1 不变。保存图表仍由已有编辑器完成。

对比界面使用同一批实验对象显示参数差异和指标差值。生成快照时校验 revision，避免用户看到旧对比而保存新结果。每次生成选择一个指标，避免混合不同量纲。散点选项为实验类别轴上的指标点图。缺失值显示为缺失，不作为 0；至少两个实验具有有效指标才能生成图表。

## 页面结构

- 实验页：搜索 / 状态 / 标签筛选，实验多选、参数与指标摘要、固定数据版本链接、编辑与复制配置。
- 录入弹窗：基本信息、键值表单、可切换高级 JSON、版本关联、备注；复制只带参数与标签，清空结果和关联。
- 对比工作区：2–8 个实验并排，基线选择、参数差异高亮、数值指标与绝对差值、指标方向、生成图表。
- 编辑器与数据页：来源快照可查看；跳转到来源版本后仍可下载原始文件。

本批不执行训练、不推断统计显著性、不将非数值指标强制转换成数字。
