03 · ASSISTANT

说出想改的地方。
先预览，再应用。

绘图助手只能通过 13 个受校验的工具修改图表：3 个只读，10 个可预览修改。每次调整先成为提案，你确认后整组应用，一步就能撤销。

  • 与你的手动编辑合并，有冲突时拦截
  • 限制步数、预算与超时，随时可以取消
  • 接入任意兼容 Chat Completions 的模型，密钥只留在本机后端
