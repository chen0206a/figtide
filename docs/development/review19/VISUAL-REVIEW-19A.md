## 四、线宽与配色（仓库主人新增要求，和返工一起做）

### 线宽：按成品尺寸，整体加粗

现在的线在成品上大约 0.5–0.8 pt，屏幕和打印都发虚。统一改为（全部按成品 pt 计算，再换算成 mm；不随屏幕缩放变化）：

| 元素 | 线宽（成品） |
|---|---|
| 图元轮廓、节点边框 | **1.0 pt** |
| 连线（激活、流程、转运、间接） | **1.25 pt** |
| 抑制线的 T 形端点 | 连线宽度 × 1.7 |
| 光路光束 | 1.8 pt |
| 分区边框、面板、放大框 | 0.75 pt |
| 磷脂头描边 | 0.5 pt |
| 放大引线（虚线） | 0.6 pt |
| 细胞核双层膜 | 两条线各约 0.75 pt，总宽约 1.15 mm |

- 箭头长 2.5 mm、宽约 1.1 mm，和 1.25 pt 线匹配；
- 正文字号默认 **7 pt**（最小仍按期刊要求检查，默认 6 pt 门槛不变）；
- 6 种风格共用这套线宽，风格只改形状和填充；手绘风格可以在此基础上乘 1.3。
- 原型 `diagram-engine-sketch.js` 已按这套数值更新（`wOutline` / `wEdge` / `wZone`），可直接对照。

### 配色：贴近真实论文

真实论文里的机制图通常是：**每个语义角色一个色相，轮廓用该色相的饱和色，填充用同色约 15–20% 的浅色**，强调色（药物、抑制、本文模块）只用一种红或橙，其余灰色。现在的实现是“蓝绿两色 + 大面积浅填充”，和期刊风格差得远。

1. 新增**配色**这一维度，和风格分开（风格管形状，配色管颜色），新建页、编辑器都能切换，存进 `style.palette`（可选字段，缺省 `okabe-ito`）。
2. 第一版内置 6 套（数值见原型 `MECH_PALETTES`）：
   - **色盲友好（Okabe–Ito）**：默认；
   - **NPG / AAAS / NEJM / Lancet / JAMA 风格**：色值参考 ggsci 包整理的期刊常见配色。只引用色值（事实数据），不复制 ggsci 的 R 代码（ggsci 是 GPL-3）。界面上写“××风格（非官方）”，在 `docs/DIAGRAMS.md` 注明来源；
3. 角色映射：主体 a、效应 b、强调 c（药物、抑制、本文模块）、配体 d、中性 n。填充 = 色值与白色按 82% 混合，轮廓 = 色值加深 8%；膜和核膜取主体色、配体色的浅色；
4. 每套配色都要过 D3 色觉检查（三种色觉缺陷下两两 ΔE00 ≥ 20）。期刊配色里如果有不达标的色对，界面上提示“这套配色有两种颜色色盲读者可能分不清”，**不要为了通过检查偷偷改色值**；
5. 线稿极简风格不受配色影响（只用黑线 + 强调色）。

效果参考：`palettes-demo.png`（同一张图在 4 套配色下的样子，以及方法框架图的两套配色）。
