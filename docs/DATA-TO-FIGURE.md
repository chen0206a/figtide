# 从文件到科研图表

## 使用

进入项目的数据管理页，点击“上传数据文件”。先检查服务器返回的预览、类型、缺失值和字段角色，再确认导入。数据页新增“选择绘图方案”：可以直接手动选择，也可以描述目标、明确同意发送元数据后请求已配置模型推荐。

推荐提供 1–3 种不同图型、理由、限制和真实字段映射。选择卡片后，右侧用完整已导入数据预览，左侧同步为选中映射并允许继续修改。只有点击“创建图表并编辑”，才经服务端 lint 创建初始图表版本；随后使用现有编辑器、保存、版本及 SVG/PNG/PDF 导出。

推荐范围：折线、分组柱状、散点、热力、箱线、小提琴、直方、经验分布。ROC/PR/混淆矩阵仍可在编辑器中配置；选图助手不猜测标签、预测分数或阳性类别的科学含义。无模型时手动选图、编辑和导出全部可用。

## 文件支持

| 扩展名 | 解析规则 |
| --- | --- |
| CSV | 默认逗号，可选分号、制表符、竖线、自动识别；保留引号内换行和分隔符 |
| TSV | 固定制表符 |
| TXT | 默认检测逗号、制表符、分号、竖线；可显式选择 |
| XLSX | 显式选择工作表；拒绝宏、公式，不执行代码 |
| JSON | 对象数组、单对象，或嵌套对象中的记录数组；多个数组必须用户选择 JSON Pointer 路径 |
| JSONL | 每个非空行一个对象；坏行给出物理行号并阻止提交，不静默跳过 |

文本均要求 UTF-8，可带 BOM。共用 10 MiB、20,000 行、100 列、200,000 单元格限制。JSON 嵌套对象展开为 `metrics.accuracy` 等字段，联合全部记录的字段并以空值填补缺失；展开重名、重复 JSON 键、记录内数组、尾随代码和深度超限均拒绝。日期、布尔和普通字符串保留为文本；不擅自推断时区或展开数组。

超出 JavaScript 安全整数范围的整数字面量默认保留为文本并警告；强制转数值时产生问题，不能悄悄舍入。原文件字节、内容指纹及解析规则保存在不可变数据版本中，预览和正式导入使用同一个解析器。

尚不支持旧版 XLS、Parquet、HDF5、TensorBoard 事件或压缩包。可以先导出为上述表格/JSON 格式；本次没有承诺自动理解任意日志或论文图片。

## Agent 与接口边界

复用 `POST /projects/{p}/agent/runs`，新增可选 `mode: "recommend"`；缺省仍为 `edit`，旧客户端不受影响。推荐绑定 `config.datasetVersionId`，`chart_id` 为 null、`base_revision` 为 0，不接受 `parent_run_id`。config 仅作为经过校验的数据版本信封，模型接收的系统上下文是字段统计画像，不是现有编辑器默认图型。

推荐工具集只有 `get_dataset_profile`、`get_figure_spec`、`recommend_charts`。最后者只返回方案，无法调用保存、修改、执行代码或统计检验。服务端验证每个字段属于该项目真实数据版本、类型正确且有观测值；同批工具调用要么全部成功，要么全部撤回。人工确认前不写 charts/chart_versions，也不改数据。

`recommend_charts` 参数：

```json
{"charts":[{"type":"line","x":"epoch","ys":["accuracy"],"group":"","heatY":"","heatZ":"","title":"训练准确率","reason":"比较准确率随轮次的变化","caveat":"按原始行顺序连接，不自动排序。"}]}
```

返回 run 的 `status: "answered"`、`mode: "recommend"`，成功时包含带服务端 id 的 `recommendations`。没有可用方案时可只返回追问文本。客户端要求审计成功 `persisted: true` 后才展示方案。此模式不会产生可直接应用的 `proposal`。

沿用步数、token 预算、超时、取消、请求 ID 幂等和审计。提示词版本 `chart-recommender-v1`；工具目录哈希单独计算。浏览器轮询仅查询状态，不自动重复模型请求；启动响应丢失时按预生成请求 ID 恢复。关闭面板取消其拥有的活跃请求。

默认不发送原始数据行、文件名、字段样例；会发送字段名、类型、基数、缺失及极值摘要和用户主动输入的目标。字段名和摘要仍可能敏感，调用前需要用户明确同意。推荐文本/方案不作为新的原始数据写入，也不在审计中持久化完整文字；工具参数按现有隐私规则摘要化。重启后保留审计和预算，未创建的推荐方案不恢复；确认创建的完整配置正常存储和恢复。

## 验证

Java 测试覆盖 TSV/自动分隔符、中文/BOM、JSON 联合字段/空值/长整数、多数组路径、JSONL 坏行、重复键/尾随代码/数组单元格/展开碰撞，以及真实 MySQL 的 preview 不落库、同规则 commit 和原始字节下载。Agent 集成验证只读工具目录、真实字段推荐及修改工具越权失败。

前端测试覆盖真实映射、不生成误差数据、同意后调用模型、选择后 lint+保存、校验失败、关闭取消和丢失启动响应的只读恢复。Chrome 用本地 OpenAI 协议夹具执行 Java 循环，验证 JSONL→推荐→选定散点→MySQL→刷新→SVG，以及多数组 JSON→显式选择→手动选图。夹具只验证系统协议和交互，不代表真实模型推荐质量。
